# DemoPop logo drafts

Four exploratory directions: 01 Lift, 02 Reveal, 03 Linked, 04 Breakout.

Open index.html to compare Paper, Ink, and Cobalt treatments. Each direction includes a transparent SVG symbol and an editable SVG wordmark. The wordmarks embed the existing DM Sans font; its OFL license is included. Colors: ink #090a0d, lime #dfff86, cobalt #536bff.

These are design drafts, not an adopted identity. The live product logo is unchanged.
